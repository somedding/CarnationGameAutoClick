# 🌸 카네이션 게임 자동 클릭 프로그램 🌸

아이폰 미러링으로 플레이하는 토스 의 카네이션 게임을 자동으로 클릭해주는 프로그램입니다! 🎮

## ✨ 주요 기능

- 🎯 미리 지정된 15개 고정 좌표에서 카네이션을 자동으로 감지하고 클릭
- 🎨 핑크색/붉은색 카네이션 색상 자동 인식 (갈색 오인식 방지 기능 포함)
- ⏱️ 25초 동안 자동 플레이 기능
- 📊 클릭 수와 남은 시간 표시
- 🚀 초고속 처리를 위한 멀티스레딩 최적화

## 🛠️ 설치 방법

1. Python 3.x 설치가 필요합니다.
2. 필요한 라이브러리를 설치합니다:
```
pip install pyautogui pillow numpy
```

## 🎮 사용 방법

1. 아이폰 미러링 프로그램으로 컴퓨터에 게임 화면을 띄웁니다.
2. 프로그램을 실행합니다:
```
python carnation_game_auto_click.py
```
3. 실행 후 자동으로 카네이션 클릭이 시작됩니다!
4. 중단하려면 `Ctrl+C`를 누르세요.

## 🔍 동작 원리

- 게임 화면 영역을 고정 좌표 (25, 434, 379, 995)로 설정합니다.
- 15개의 고정된 셀 좌표에서 카네이션 색상을 확인합니다:
  ```
  1셀: 82*496    | 2셀: 203*500   | 3셀: 325*487
  4셀: 82*599    | 5셀: 203*599   | 6셀: 325*599
  7셀: 82*710    | 8셀: 203*710   | 9셀: 325*710
  10셀: 82*812   | 11셀: 203*812  | 12셀: 325*812
  13셀: 82*920   | 14셀: 203*920  | 15셀: 325*920
  ```
- 핑크색/붉은색 카네이션만 클릭하고 갈색 꽃이나 줄기는 무시합니다.
- 캐싱을 통해 색상 판단 속도를 최적화했습니다.

## 🔧 커스터마이징

`carnation_game_auto_click.py` 파일에서 다음 값을 조정할 수 있습니다:
- `game_area`: 게임 영역 좌표
- `fixed_points`: 각 셀의 중심 좌표
- `duration`: 게임 실행 시간(초)
- `click_duration`: 클릭 유지 시간

## ⚠️ 주의사항

- 화면 해상도나 미러링 앱에 따라 좌표 조정이 필요할 수 있습니다.
- 프로그램은 화면의 색상을 기반으로 동작하므로 게임 화면이 가려지지 않도록 해주세요.
- 게임 업데이트로 인해 색상이 변경되면 코드 내 색상 범위를 조정해야 할 수 있습니다.

## 🎯 성능 팁

- 디버그 모드가 켜져 있으면 처음 10초 동안 색상 정보가 출력됩니다.
- 고정된 좌표만 확인하므로 CPU 사용량이 낮습니다.
- 멀티스레딩을 사용해 동시에 여러 좌표를 확인합니다.
