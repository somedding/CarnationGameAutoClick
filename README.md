# 카네이션 게임 자동 클릭 프로그램

이 프로그램은 아이폰 미러링을 통해 플레이하는 카네이션 게임을 자동으로 클릭해주는 도구입니다. 화면에서 카네이션을 인식하여 자동으로 클릭합니다.

## 설치 방법

1. 필요한 라이브러리 설치:
```
pip install -r requirements.txt
```

## 사용 방법

1. 아이폰 미러링을 연결하고 카네이션 게임을 실행합니다.
2. 다음 명령어로 프로그램을 실행합니다:
```
python carnation_game_auto_click.py
```

3. 프로그램이 실행되면 게임 진행 시간을 입력하세요 (기본값: 20초)
4. 프로그램은 설정된 시간 동안 카네이션을 자동으로 감지하고 클릭합니다.
5. 언제든지 `Ctrl+C`를 눌러 프로그램을 중단할 수 있습니다.

## 게임 영역 설정

- 게임 화면 영역은 좌표 (25, 434)부터 (379, 995)까지로 고정되어 있습니다.
- 이 좌표는 특정 화면 해상도와 아이폰 미러링 설정에 맞게 조정되었습니다.
- 다른 화면 설정을 사용하려면 코드 내의 game_area 값을 수정해야 합니다.

## 최적화 정보

- 프로그램은 색상 기반 감지 방법을 사용하여 분홍색 배경에서 빨간 카네이션만 클릭합니다.
- 성능 향상을 위해 각 셀의 중앙 부분만 작은 샘플로 검사합니다.
- 감지 주기는 0.01초로 매우 짧아 실시간으로 나타나는 카네이션을 즉시 클릭할 수 있습니다.
- 3x5 그리드를 사용하여 게임 화면 전체를 커버합니다.

## 주의사항

- Mac에서 PyAutoGUI를 사용하려면 접근성 설정에서 권한을 부여해야 합니다:
  시스템 환경설정 > 개인 정보 보호 및 보안 > 개인 정보 보호 > 접근성
- 이미지 인식은 화면 해상도, 색상 설정, 빛 반사 등에 영향을 받을 수 있습니다.
